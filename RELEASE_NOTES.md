# Release Notes

## Version 1.4.2

- Updated yamipa.core dependency to 1.4.2
- Enhanced LocaleService with bundled default language configurations
- Updated wiki documentation
- Improved editor permission settings
- Added image search functionality
- Added image size editor feature
- Fixed language localization support

## Key Features

- **Image Search**: Filter images by filename using the search button
- **Image Editor**: Resize images directly from the claim menu
- **Permission System**: Configurable permissions for editor access
- **Multi-language Support**: Full Spanish and English localization
- **Anti-exploit Protection**: Built-in safeguards for secure gameplay
